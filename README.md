# Kaafia : The Italian Cafe

## Website Purpose
A professional business website for **Kaafia**, a local Italian cafe located in Gorakhpur, India.  
This project was developed as part of the **IIMB Website Development Final Project**.

## Features
- Fully responsive navigation with mobile-friendly hamburger menu.
- Hero section with clear call-to-action.
- Categorized digital menu with item descriptions and prices.
- Responsive image gallery showcasing the cafe’s ambiance.
- Contact form with frontend validation and success feedback.
- Modern, clean design using warm neutral colors for a cozy Italian vibe.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Variables)
- Vanilla JavaScript

## Project Structure
- `index.html` → Home page with hero section and highlights  
- `about.html` → Cafe story and values  
- `menu.html` → Categorized food & beverage menu  
- `gallery.html` → Visual gallery of the cafe  
- `contact.html` → Contact form and information  
- `style.css` → Centralized styling (colors, layout, responsiveness)  
- `script.js` → Interactive functionality (menu toggle, form validation)
