# Kaafia :The Italian Cafe

## Website Purpose
A professional business website for a local Italian cafe located in Gorakhpur, India. Designed for the IIMB Website Development Final Project.

## Features
- Fully responsive navigation with mobile hamburger menu.
- Hero section with call-to-action.
- Categorized digital menu with descriptions and prices.
- Responsive image gallery.
- Contact form with frontend validation and success feedback.
- Modern, clean design using warm neutral colors.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Variables)
- Vanilla JavaScript

## Project Structure
- index.html (Home)
- about.html (Story and Values)
- menu.html (Categorized Menu)
- gallery.html (Visuals)
- contact.html (Form and Info)
- style.css (All styling)
- script.js (Functionality)

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any modern web browser.

## Deployment
This website is ready for GitHub Pages.
1. Push the code to a GitHub repository.
2. Go to Settings > Pages.
3. Select 'main' branch and save.
